# mdview

[![CI](https://github.com/khgouldy/mdview/actions/workflows/ci.yml/badge.svg)](https://github.com/khgouldy/mdview/actions/workflows/ci.yml)

A tiny, fully local iOS Markdown viewer: open any `.md` file from Files or the share sheet and read it beautifully. One toggle: Rendered / Source.

Status: planning. See `docs/plans/mdview/` on the `plan/mdview` branch.
