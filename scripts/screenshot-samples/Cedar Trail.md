# Cedar Trail

Cedar is a weekend loop above the river. The first mile is shaded, then the ridge opens up.

- Cedar starts at the ridge gate
- Carry water for the climb
- Turn around if the rock is wet

- [x] Check the weekend weather
- [ ] Leave a note for Maya

```swift
print(trail.count)
```
